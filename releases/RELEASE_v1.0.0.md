## 🚀 Overview

HunterXJob v1.0.0 is the official mobile client for the HunterXJob autonomous job search and application platform. It connects securely to the HunterXJob backend engine to search job boards, score candidate fit, preview application forms, and manage review queues directly from your Android device.

## 📦 How to Install

1. Download [`HunterXJob-v1.0.0.apk`](./HunterXJob-v1.0.0.apk).
2. On your Android phone, enable **Install unknown apps** for your browser or file manager.
3. Open `HunterXJob-v1.0.0.apk` and tap **Install**.
4. Launch the app and enter your HunterXJob backend server URL and API key.
5. Upgrade to **HunterX Pro** anytime in the app under **Settings → Plan & Subscription** using license code `HUNTERX-PRO-2026`.
